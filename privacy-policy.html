DocuView는 문서를 기기 안에서만 읽는 오프라인 뷰어입니다. 회원가입·로그인, 서버 전송, 광고, 분석 도구를 사용하지 않으며, 사용자가 선택한 문서와 그에 따른 최소한의 기록만 기기 내부에 저장합니다.

이 방침은 Donian(이하 “개발자”)이 제공하는 Android 문서 뷰어 DocuView에만 적용됩니다. 다른 앱이나 웹사이트에 적용되지 않으며, 아래 내용은 실제 앱 구현을 기준으로 작성되었습니다.

1.적용 범위와 핵심 원칙

  • 대상: DocuView Android 앱 v1.1.0 (kr.docuview.app). Google Play를 통해 배포되는 이 앱 자체에 한정됩니다.
  • 기능: PDF·HWP·HWPX 문서 열람, 최근 문서 목록, 페이지 이동·북마크, 문서 찾기, 파일 열기·삭제, 문서 위 주석 작성(자유 그리기·형광펜, 5색) 및 주석이 포함된 페이지 이미지 공유입니다. 문서 원본 편집이나 서버 업로드는 제공하지 않습니다.
  • 오프라인 원칙: 앱은 인터넷(INTERNET) 권한을 선언하지 않습니다. 개발자 서버로 데이터를 보내지 않으며, 외부 API를 호출하지 않습니다.
  • 계정·결제·광고 없음: 회원가입, 로그인, 인앱 결제, 구독, 광고 기능이 없으므로 계정 정보나 결제 정보, 광고 식별자를 처리하지 않습니다.

2.처리하는 정보 항목과 방법

앱이 기기에서 처리·보관하는 정보는 다음과 같습니다. 이 정보는 모두 이용자의 기기 안에 남고 외부로 전송되지 않습니다.

항목포함되는 값생성·수집 방법
문서 원본 또는 사본 이용자가 선택하거나 다른 앱에서 열어 준 PDF/HWP/HWPX 파일 내용 시스템 파일 선택기 또는 외부 열기 요청으로 받은 파일을 읽습니다. content:// URI는 앱 내부 filesDir/documents/에 사본을 만들고, file:// URI는 원본 경로를 직접 사용합니다.
문서 메타데이터 SHA-256 내용 해시 기반 문서 ID, 표시 이름, 확장자, 로컬 경로, 파일 크기, 마지막 열람 시각, 마지막 페이지, 전체 페이지 수 문서를 가져올 때 생성하고, 열람 중 페이지가 바뀔 때 갱신하여 Room 데이터베이스에 저장합니다. 해시는 같은 내용의 파일 중복을 막는 식별자로만 사용합니다.
북마크 문서 ID, 페이지 인덱스(내부적으로 0부터 시작), 생성 시각 이용자가 뷰어에서 북마크를 추가할 때 저장하고, 삭제할 때 제거합니다.
주석 데이터 문서 ID, 페이지 인덱스, 도구(그리기/형광펜), 색상(빨·주·노·초·파), 정규화 좌표, 생성 시각 이용자가 뷰어에서 주석을 작성할 때 Room 데이터베이스에 저장하며, 되돌리기·초기화로 삭제할 수 있습니다. 주석은 원문 파일에 병합되지 않고 기기에만 저장됩니다.
앱 설정 마지막 페이지 복원 여부, 컴팩트 뷰, 화면 켜짐 유지, 테마 모드 이용자가 설정 화면에서 변경한 값을 SharedPreferences에 저장합니다.
문서 찾기 캐시 외부 저장소에서 발견한 PDF/HWP/HWPX 파일의 절대 경로와 스캔 완료 여부 이용자가 ‘문서 찾기’를 실행할 때 파일 이름과 경로만 확인해 캐시합니다. 문서 내용은 읽지 않습니다.
임시 캐시 앱 실행 중 생성되는 임시 파일 앱 캐시 디렉터리에 저장되며, 설정 화면에서 용량 확인과 삭제가 가능합니다.

앱은 단말의 연락처, 위치, 사진·카메라, 마이크, SMS, 통화 기록, 기기 식별자(AD_ID 포함)를 읽지 않습니다.

3.정보 이용 목적

  • 이용자가 선택한 문서를 화면에 표시하고 페이지를 이동하거나 마지막 읽던 위치를 복원합니다.
  • 최근 문서 목록, 페이지 북마크, 문서 찾기 결과를 기기에서 제공합니다.
  • 이용자가 문서 위에 주석(그리기·형광펜)을 작성하고, 주석이 포함된 페이지를 PNG 이미지로 생성해 기기 내 다른 앱(카카오톡·메일·메시지 등)으로 공유합니다.
  • 이용자가 설정한 화면·읽기 환경을 다음 실행에도 유지합니다.
  • 문서 찾기에서 이용자가 직접 선택한 파일을 열거나 삭제합니다.
  • PDF는 Android 플랫폼 렌더러로, HWP/HWPX는 앱에 내장된 WebAssembly 렌더러로 화면에 표시합니다.

위 목적 외의 용도, 특히 광고, 사용자 프로파일링, 통계 분석, 서버 저장에는 사용하지 않습니다.

4.저장 위치와 보유 기간

  • 문서 사본: 앱 내부 저장소 filesDir/documents/에 보관합니다. 원본 파일은 수정하지 않습니다.
  • 메타데이터·북마크·주석: 앱 내부 데이터베이스 docuview.db에 보관합니다.
  • 설정·스캔 캐시: 앱 전용 SharedPreferences에 보관합니다.
  • 임시 캐시: 앱 캐시 디렉터리에 보관하며, 이용자가 ‘설정 > 캐시 비우기’로 즉시 삭제할 수 있습니다.

보관 기간은 이용자가 해당 데이터를 삭제하거나 앱을 제거할 때까지입니다. 개발자 서버나 클라우드에 별도로 백업하지 않으며, 앱은 allowBackup=false로 설정되어 있습니다. 앱을 삭제하면 내부 문서 사본, 데이터베이스, 설정, 캐시가 함께 제거됩니다.

‘설정 > 최근 문서 정리’는 데이터베이스의 최근 열람 기록(이에 연결된 북마크 포함)만 지웁니다. 외부 저장소의 원본 파일과 앱 내부 문서 사본 자체는 삭제하지 않습니다.

5.외부 전송 및 제3자 제공 여부

  • 앱에는 인터넷 권한이 없으므로 문서, 메타데이터, 북마크, 주석, 설정 값이 외부로 전송되지 않습니다. 주석 페이지 공유는 이용자가 공유 버튼을 눌렀을 때 이용자가 선택한 앱으로만 기기 내에서 이루어지며, 개발자 서버에는 전송되지 않습니다.
  • Firebase, Google Analytics, Crashlytics, AdMob, Google Play Billing, 외부 AI API 등 데이터를 수집하는 제3자 SDK를 사용하지 않습니다.
  • HWP/HWPX 렌더링에는 오픈소스 @rhwp/core(MIT)를 사용합니다. 이 라이브러리는 앱 번들에 포함되어 기기에서만 동작하며, 별도 서버로 데이터를 보내지 않습니다. 구성 요소 목록은 프로젝트의 LICENSES.md에서 확인할 수 있습니다.
  • 개발자는 개인정보 처리업무를 외부에 위탁하지 않고, 국외로 이전하지 않으며, 수집한 정보를 판매하거나 제3자에게 제공하지 않습니다. 가명정보·민감정보를 별도로 처리하거나 자동화된 결정을 수행하지도 않습니다.
  • Google Play 스토어의 설치·배포 과정에서 Google이 자체 정책에 따라 처리하는 정보는 Google의 개인정보처리방침에 따르며, 이는 앱이 수집하는 정보와는 별개입니다.

6.기기 권한 사용

앱은 아래 두 가지 파일 관련 권한만 선언합니다.

  • READ_EXTERNAL_STORAGE (Android 10 이하, maxSdkVersion=30): 외부 저장소의 문서를 찾고 열기 위해 사용합니다.
  • MANAGE_EXTERNAL_STORAGE (Android 11 이상): ‘모든 파일 접근’ 권한이 필요한 기기에서 문서 찾기와 사용자가 선택한 파일 삭제를 위해 사용합니다.

이 권한은 ‘문서 찾기’ 기능을 실행할 때 요청되며, 파일 이름과 경로를 확인하고 사용자가 지정한 파일을 여는 용도로만 씁니다. 권한을 허용하지 않아도 시스템 파일 선택기로 문서를 열 수 있습니다. 권한은 Android 설정 또는 앱의 ‘설정 > 파일 접근 권한 취소’에서 언제든지 철회할 수 있습니다.

문서 찾기는 외부 저장소를 순회하며 최대 500개 파일, 200,000개 디렉터리까지만 확인합니다. 이 과정에서 문서 내용을 읽거나 전송하지 않습니다.

7.HWP 렌더링(WebView) 처리

HWP/HWPX 문서는 앱에 내장된 WebView와 WebAssembly 렌더러로 열립니다. WebView는 다음과 같이 제한됩니다.

  • 내장 HTML·JavaScript·WASM 파일과 선택된 문서 한 개만 제공합니다. 그 밖의 모든 요청은 차단됩니다.
  • 가상 주소 https://docviewer.local에 대한 요청만 가로채며, 실제 외부 네트워크 접근은 허용하지 않습니다.
  • 파일 접근(allowFileAccess=false), 콘텐츠 접근(allowContentAccess=false), DOM 저장소, 새 창 생성, 혼합 콘텐츠를 비활성화했습니다.
  • 쿠키를 직접 저장하거나 제3자 쿠키를 허용하지 않으며, 응답에 Cache-Control: no-store를 적용합니다. 뷰어 종료 시 WebView 기록을 지우고 파기합니다.
  • 문서 내용은 파싱을 위해 WebAssembly 메모리에 로드됩니다. 메모리 보호를 위해 HWP/HWPX는 64MiB, PDF는 256MiB로 파일 크기를 제한합니다.

8.데이터 삭제 방법

계정 삭제: DocuView는 회원가입과 로그인을 제공하지 않으므로 관리할 계정이 없습니다. 따라서 별도의 계정 삭제 절차는 없습니다.

  1. 개별 문서(외부 파일) 삭제: ‘문서 찾기’에서 파일을 길게 눌러 [삭제]를 선택하고 확인하세요. 선택한 파일은 휴지통으로 이동하지 않고 즉시 영구 삭제되며 복구할 수 없습니다. 함께 저장된 앱 내 관련 기록도 제거됩니다.
  2. 최근 기록 정리: [설정 > 최근 문서 정리]에서 최근 열람 목록과 북마크를 삭제할 수 있습니다. 원본 파일은 그대로 유지됩니다.
  3. 임시 캐시 삭제: [설정 > 캐시 비우기]에서 앱 캐시 디렉터리를 비웁니다.
  4. 전체 데이터 삭제: Android 설정에서 앱을 제거(삭제)하면 내부 문서 사본, 데이터베이스, 설정, 캐시가 모두 삭제됩니다.

앱 내부에 복사된 문서 사본은 앱을 제거할 때 함께 지워집니다. 앱 내에서 사본 하나씩만 지우는 별도 메뉴는 제공하지 않습니다. 서버에 저장된 데이터가 없으므로 이메일로 별도 삭제 요청을 보낼 필요가 없습니다. 문의는 아래 연락처로 주세요.

9.이용자 권리와 아동의 개인정보 보호

  • 이용자는 자신의 정보에 대한 열람, 정정, 삭제, 처리 정지 및 동의 철회를 요청할 수 있습니다. 모든 정보가 기기에 있으므로 위 8항의 앱 내 삭제 방법을 사용하면 즉시 반영됩니다.
  • 법정대리인을 포함한 권리 행사 요청은 아래 개인정보 보호책임자 이메일로 보내 주시면 확인 후 조치하겠습니다.
  • DocuView는 아동을 대상으로 설계되지 않았으며, 아동의 개인정보를 의도적으로 수집하지 않습니다. 광고 식별자를 수집하지 않고, Google Play 가족 정책(Families Policy)을 준수합니다.

10.안전성 확보조치

  • 데이터를 앱 전용 내부 저장소에 보관하고, 외부 백업을 비활성화했습니다(allowBackup=false).
  • 인터넷 권한이 없고, 평문 통신(usesCleartextTraffic=false)과 WebView의 외부 URL 로딩을 차단했습니다.
  • WebView를 샌드박스로 구성하고, 선택된 문서와 내장 리소스 외의 접근을 거부합니다.
  • 파일 크기 제한(256MiB/64MiB)과 파일 형식 검사로 비정상적인 파일 처리를 줄입니다.
  • 필요한 파일 권한만 요청하며, 이용자가 언제든 철회할 수 있습니다.

11.자동 수집 장치 (쿠키·광고 식별자)

DocuView는 쿠키, 웹 비콘, 광고 식별자(AD_ID/AAID), 분석 SDK를 사용하지 않습니다. HWP 뷰어의 WebView는 DOM 저장소를 비활성화하고, 쿠키를 직접 저장하거나 제3자 쿠키를 허용하지 않으며, 외부 도메인 요청을 모두 차단합니다. 내장 리소스 응답은 캐시하지 않습니다.

따라서 자동 수집을 거부하기 위한 별도의 앱 설정은 없으며, 거부로 인해 제한되는 기능도 없습니다.

DocuView is an offline document viewer. All reading happens on your device. We do not use accounts, server uploads, ads, or analytics; only the documents you choose and the minimal records needed to read them are stored locally.

This policy applies only to the Android app DocuView provided by Donian (“Developer”). It does not cover other apps or websites. The descriptions below reflect the app’s actual implementation.

1.Scope and Key Principles

  • Scope: DocuView for Android v1.1.0 (kr.docuview.app) only.
  • Features: Read PDF, HWP, and HWPX documents; recent documents list; page navigation and bookmarks; document discovery; opening and deleting user-selected files; annotations (freehand pen and highlighter in 5 colors) and sharing annotated page images. Editing original documents or uploading to servers is not provided.
  • Offline by design: The app declares no INTERNET permission. It does not send data to developer servers and does not call external APIs.
  • No accounts, purchases, or ads: There is no sign-up, login, in-app purchase, subscription, or advertising, so no account, payment, or advertising identifier is processed.

2.Information We Process and How

All of the following information stays on your device and is never transmitted.

ItemValuesHow it is created
Document files Contents of PDF/HWP/HWPX files you select or that another app opens with DocuView Read from the system file picker or an external open intent. For content:// URIs, a copy is stored in internal filesDir/documents/. For file:// URIs, the original path is used directly.
Document metadata SHA-256 content-hash document ID, display name, extension, local path, file size, last opened time, last page, total pages Created when a document is imported and updated as pages change; stored in the local Room database. The hash is used only to deduplicate identical content.

The app does not read contacts, location, camera or photos, microphone, SMS, call logs, or device advertising identifiers (including AD_ID).

3.How We Use Information

  • To display your selected document, navigate pages, and restore the last reading position.
  • To show the recent documents list, bookmarks, and local document discovery results.
  • To draw annotations (pen, highlighter) on a page and generate a PNG of that annotated page to share via other apps on your device (KakaoTalk, email, messages, etc.) when you tap Share.
  • To keep your reading and display preferences between launches.
  • To open or delete a file you explicitly select in document discovery.
  • To render PDFs with the Android platform renderer and HWP/HWPX with the bundled WebAssembly renderer.

Information is not used for advertising, profiling, analytics, or server-side storage.

4.Storage and Retention

  • Document copies: internal app storage at filesDir/documents/. Original files are not modified.
  • Metadata, bookmarks, and annotations: internal database docuview.db.
  • Settings and scan cache: app-private SharedPreferences.
  • Temporary cache: app cache directory, removable via [Settings > Clear cache].

Information is kept until you delete it or uninstall the app. Nothing is backed up to developer servers or the cloud; the app sets allowBackup=false. Uninstalling removes internal document copies, the database, settings, and cache.

[Settings > Clear recent documents] removes database history and its linked bookmarks only. Original files and internal document copies are not deleted by that action.

5.External Transmission and Third Parties

  • The app has no internet permission, so documents, metadata, bookmarks, annotations, and settings are never transmitted. Annotated page sharing happens only to apps you choose on your device when you tap Share; nothing is sent to developer servers.
  • No data-collecting third-party SDKs are used: no Firebase, Google Analytics, Crashlytics, AdMob, Google Play Billing, or external AI APIs.
  • HWP/HWPX rendering uses the open-source @rhwp/core (MIT) bundled into the app. It runs entirely on your device and sends nothing to a server. See LICENSES.md in the project for component details.
  • The Developer does not entrust processing to third parties, transfer data abroad, sell data, or share it with third parties. No pseudonymized or sensitive data is separately processed, and no automated decisions are made.
  • Information Google processes for app distribution through Google Play follows Google’s privacy policy and is separate from data handled by this app.

6.Device Permissions

The app declares only two file-related permissions:

  • READ_EXTERNAL_STORAGE (Android 10 and below, maxSdkVersion=30): to find and open documents on external storage.
  • MANAGE_EXTERNAL_STORAGE (Android 11 and above): where “All files access” is required for document discovery and deleting a file you explicitly choose.

These permissions are requested when you use “Find documents”. They are used only to check file names/paths and open files you select. You can still open documents through the system file picker without granting them, and you can revoke them at any time in Android Settings or via [Settings > Revoke file access] in the app.

Document discovery traverses at most 500 files and 200,000 directories. It does not read or transmit document contents.

7.HWP Rendering (WebView)

HWP/HWPX files are rendered in a bundled WebView with a WebAssembly renderer, restricted as follows:

  • Only bundled HTML/JavaScript/WASM assets and the single selected document are served. All other requests are blocked.
  • Only the virtual origin https://docviewer.local is intercepted; no real external network access is allowed.
  • File access (allowFileAccess=false), content access (allowContentAccess=false), DOM storage, new windows, and mixed content are disabled.
  • Cookies are not set and third-party cookies are not enabled; responses are marked Cache-Control: no-store, and the WebView history is cleared and the view destroyed when the reader closes.
  • Document content is loaded into WebAssembly memory for parsing. File size limits are 64 MiB for HWP/HWPX and 256 MiB for PDF to protect memory usage.

8.How to Delete Data

Account deletion: DocuView has no sign-up or login, so there is no account to delete and no separate account-deletion procedure.

  1. Delete an external document: Long-press the file in “Find documents”, choose [Delete], and confirm. The file is permanently deleted (not moved to Trash) and cannot be recovered. Related local records are removed too.
  2. Clear recent history: Use [Settings > Clear recent documents] to remove recent history and bookmarks. Original files are kept.
  3. Clear temporary cache: Use [Settings > Clear cache] to empty the app cache directory.
  4. Delete everything: Uninstall the app from Android Settings to remove all internal document copies, database records, settings, and cache.

Internal document copies are removed when the app is uninstalled; there is no separate menu to delete individual copies. Because no server-side data exists, no email deletion request is required. You can still contact us using the address below.

  • Requests, including those made by a legal guardian, can be sent to the Data Protection Contact below and will be handled without delay.
  • DocuView is not directed to children and does not knowingly collect children’s personal information. No advertising identifier is collected, and the app complies with the Google Play Families Policy.

10.Security Measures

  • Data is stored in app-private internal storage, with external backup disabled (allowBackup=false).
  • No internet permission; cleartext traffic (usesCleartextTraffic=false) and external URL loading in the WebView are disabled.
  • The WebView is sandboxed: only the selected document and bundled resources are accessible.
  • File size limits (256 MiB / 64 MiB) and file type validation reduce malformed-file risks.
  • Only the necessary file permissions are requested, and you can revoke them at any time.

11.Automatic Collection (Cookies / Ad ID)

DocuView does not use cookies, web beacons, advertising identifiers (AD_ID/AAID), or analytics SDKs. The HWP WebView disables DOM storage, does not set cookies or enable third-party cookies, blocks all external domains, and does not cache bundled resources.

There is therefore no separate opt-out setting in the app, and no feature is limited by opting out.
